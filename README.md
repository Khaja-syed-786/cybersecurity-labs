# Cybersecurity Labs

A hands-on collection of offensive and defensive security lab exercises covering
vulnerability assessment, exploitation, detection engineering, and compliance
gap analysis. Each lab is self-contained with its own write-up, mapped to
recognized security frameworks.

All work was performed in an **isolated lab environment owned by the author**,
using intentionally vulnerable virtual machines, for **education and skills
demonstration only**.

## 🧰 Tools

- **Nmap** — network and service discovery
- **Metasploit Framework** — exploitation
- **Wireshark** — packet capture and analysis
- **Nessus** — vulnerability scanning
- **Splunk** — log analysis and detection

## 🗂️ Frameworks & Standards

- **NIST SP 800-53** — security and privacy controls
- **ISO/IEC 27001 (Annex A)** — information security controls
- **MITRE ATT&CK** — adversary tactics and techniques

---

## ⚠️ Ethics & Scope

- All labs run in a **self-owned, isolated environment** — no production systems
  and no third-party systems are ever involved.
- Targets are **intentionally vulnerable training VMs** (e.g., Metasploitable2)
  used for learning.
- **Host-Only networking is recommended** so lab VMs cannot reach the internet
  or the host LAN.
- Content is provided for **education and authorized testing only**. Do not use
  these techniques against systems you do not own or lack explicit written
  permission to test. Unauthorized access is illegal.
